2. Réalisation 1 – Cluster HAProxy (Load balancing & Haute disponibilité)

Intitulé court

Mise en place d’un cluster web haute disponibilité avec HAProxy.

Contexte

Dans un environnement virtualisé sous VMware, j’ai déployé une architecture composée de :

  • deux serveurs web Apache (SRV‑WEB1 et SRV‑WEB2),
  • un serveur HAProxy jouant le rôle de répartiteur de charge,
  • un poste client pour les tests,
  • un réseau LAN dédié.

L’objectif était d’assurer la continuité de service d’un site web même en cas de panne d’un serveur.

Travaux réalisés

  • Installation et configuration d’Apache sur deux serveurs distincts ;
  • déploiement d’HAProxy et configuration du load balancing (round robin) ;
  • mise en place de la page de statistiques /statistique ;
  • tests d’alternance entre les serveurs (THE GRILL 1 / THE GRILL 2) ;
  • simulation de panne (arrêt d’Apache sur SRV‑WEB1) ;
  • vérification du basculement automatique vers SRV‑WEB2 ;
  • documentation de l’architecture et des résultats.

Résultats

  • Le site web reste accessible même si un serveur tombe ;
  • le trafic est réparti automatiquement entre les deux serveurs ;
  • la page de statistiques confirme l’état UP/DOWN des serveurs ;
  • le cluster répond aux exigences de haute disponibilité.

3. Réalisation 2 – Déploiement GLPI / OCS Inventory

Intitulé court

Mise en place d’une solution d’inventaire informatique avec GLPI et OCS Inventory.

Contexte

Dans le cadre d’un devoir pratique, j’ai installé et configuré GLPI, un outil de gestion de parc informatique, ainsi que OCS Inventory, permettant la remontée automatique des équipements du réseau.

Travaux réalisés

  • Installation de GLPI sur un serveur Debian ;
  • installation d’OCS Inventory Server ;
  • configuration de la base de données GLPI ;
  • connexion GLPI ↔ OCS Inventory ;
  • importation automatique des machines inventoriées ;
  • test des comptes par défaut (glpi, tech, normal, post-only) ;
  • documentation du processus d’installation.

Résultats

  • GLPI opérationnel et accessible via interface web ;
  • base de données initialisée et fonctionnelle ;
  • comptes utilisateurs prêts à l’emploi ;
  • OCS Inventory configuré pour remonter les équipements ;
  • début de gestion du parc informatique.

Compétences mobilisées (Bloc 1)
